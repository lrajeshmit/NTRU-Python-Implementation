# NTRU Python Implementation

This repository contains a Python implementation of the NTRU lattice-based public-key cryptosystem developed for educational, research, and benchmarking purposes.

## Features

* NTRU Key Generation
* NTRU Encryption
* NTRU Decryption
* Polynomial Arithmetic Operations
* Extended Euclidean Algorithm for Polynomial Inversion
* ASCII Message Encoding and Decoding
* Performance Evaluation Framework

## Software Requirements

* Python 3.7 or higher
* NumPy

## Installation

```bash
pip install -r requirements.txt
```
